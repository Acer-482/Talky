# Talky

一个基于Flutter，集情绪记录、AI 心理陪伴与兴趣社交于一体的跨平台聊天应用

## 主要功能

| 模块 | 功能 |
|-|-|
| **账户系统** | 注册、登录、资料修改（用户名/密码/描述/联系方式/兴趣标签） |
| **群聊聊天** | 创建群聊、修改群信息、加入群聊、实时文本消息、消息已读状态、历史消息加载 |
| **AI 心理助手** | 基于大模型的流式对话，支持思考内容展开，根据用户画像提供个性化回复 |
| **情绪记录** | 每日心情评分（0-10分）、日记记录、日历视图、情绪趋势折线图、昨日统计弹窗 |
| **心理支持** | 每日随机心理小知识（支持“换一换”）、兴趣标签选择 |
| **智能推荐** | 根据用户兴趣标签自动推荐匹配度高的群聊 |
| **个性化设置** | 主题色自定义、亮暗模式切换、服务器地址配置、日志查看 |
| **跨平台支持** | 支持Windows、Android平台
| **数据本地化** | 所有用户数据通过`SharedPreferences`存储于本地

## 运行环境
| 平台 | 最低版本 | 建议配置 | 备注 |
|-|-|-|-|
Windows 客户端 | Windows 10 (x64) 1809 | 2GB 内存, DirectX 11 | 不支持 Win7/8
Android 客户端 | Android 5.0 (API 21) | 1GB 内存, OpenGL ES 2.0 | 需要网络权限
服务端 | Windows 10 (x64) | 8GB 内存 | 无特殊依赖
