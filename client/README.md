# Talky

A cross-platform chat application based on Flutter, integrating emotion tracking, AI psychological companionship, and interest-based social networking.

## Main Features

| Module                         | Features                                                                                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Account System**             | Registration, login, profile editing (username/password/description/contact info/interests)                                                   |
| **Group Chat**                 | Create groups, edit group info, join groups, real-time text messages, read receipts, load message history                                     |
| **AI Psychological Assistant** | Streaming conversation based on large language models, support for displaying reasoning process, personalized responses based on user profile |
| **Mood Tracking**              | Daily mood rating (0-10), diary entries, calendar view, mood trend line chart, yesterday's statistics popup                                   |
| **Psychological Support**      | Daily random psychological tips (support "refresh"), interest tag selection                                                                   |
| **Smart Recommendation**       | Automatically recommend highly matching groups based on user interest tags                                                                    |
| **Personalization**            | Custom theme color, light/dark mode switch, server address configuration, log viewer                                                          |
| **Cross-platform Support**     | Supports Windows and Android platforms                                                                                                        |
| **Local Data Storage**         | All user data is stored locally via `SharedPreferences`                                                                                       |

## Runtime Environment

| Platform       | Minimum Version       | Recommended Configuration | Notes                       |
| -------------- | --------------------- | ------------------------- | --------------------------- |
| Windows Client | Windows 10 (x64) 1809 | 2GB RAM, DirectX 11       | Win7/8 not supported        |
| Android Client | Android 5.0 (API 21)  | 1GB RAM, OpenGL ES 2.0    | Requires network permission |
| Server         | Windows 10 (x64)      | 8GB RAM                   | No special dependencies     |
